# Проверка реализации NSControl

Дата: 15.10.2026. Проверена новая реализация по итоговому ТЗ 2.3. Это отчёт о доступных программных проверках, а не протокол приёмки на контрольном оборудовании.

## Подтверждено в среде разработки

- Flutter 3.47.7, Dart 3.13.5; зависимости восстановлены с `pub get --enforce-lockfile`.
- `bash tools/verify.sh`: анализатор без замечаний, **71 Flutter-тест**, **8 Python-тестов** прошли.
- `AlertGate.swift` с отдельным CLI harness: **21 проверка** TTL, повторов, отмены, clock sync и смены сеанса прошла.
- UI-тесты: русские экраны, вертикальная область 430×932, горизонтальная 1000×600, тёмная тема и переходы между вкладками. Визуально проверен рендер с реальными шрифтами и значками.
- SQLite проверяется настоящей in-memory базой: связи и транзакции, восстановление после сбоя, каскадное удаление, замена стадий сна, CSV, исключение чувствительных данных и объединение недоступных интервалов.
- Независимое ревью проверило межмодульное поведение. Исправлены повторное открытие камеры запоздалым запуском после сворачивания, блокировка остановки камерой ожидания часов, перезапись раннего ACK статусом sent, влияние пробы звука на активную тревогу, устаревшие записи сна после удаления/ошибки базы, потеря часами синхронизации при смене сеанса, отображение связанной рекомендации глаз, скрытая тревога на другой вкладке и повторные запросы после отказа в камере.

Регрессионные тесты проверяют фактическое поведение контроллеров с реальной SQLite и управляемыми внешними границами. Искусственные измерения используются только в тестах; рабочее приложение читает реальную камеру и нативные API.

## Сборки и оборудование

Android release APK успешно собран командой `bash tools/build_android.sh --target-platform android-arm64`. Финальная повторная сборка с прогретым кэшем завершилась за 4,4 с. Проверены нативная Kotlin-компиляция, R8, упаковка и подпись.

- Файл: `build/app/outputs/flutter-apk/app-release.apk`, 31 203 598 байт.
- Пакет: `org.nscontrol.nscontrol`, версия `1.0.0`, versionCode `1`.
- minSdk 26, targetSdk 36, только `arm64-v8a`; библиотеки движка и детектора соответствуют ABI.
- Подпись APK Signature Scheme v2 проверена `apksigner`; используется Android Debug certificate для локального стенда.
- `RECORD_AUDIO` отсутствует в итоговом manifest. Камера, вибрация и READ_SLEEP присутствуют; зависимости SDK также добавляют INTERNET и ACCESS_NETWORK_STATE.
- SHA-256: `e8441fd5fc7fb6fd23bd14e590efa07a39020378f8a2872cef18479abb084e15`.

SDK, JDK, Gradle, NDK и CMake установлены локально. Успешная сборка не заменяет установку и испытания на Huawei.

На Mac отсутствует полный Xcode, имеются только Command Line Tools/Swift CLI. Поэтому полная сборка и установка iOS/watchOS **не подтверждены**. Проверки Swift-протокола не заменяют компиляцию WatchConnectivity/HealthKit и запуск на Apple Watch.

Garmin Connect IQ SDK 9.2.0 установлен, `monkeyc --version` работает. Сборка под fēnix 7X требует профиля устройства, загружаемого через SDK Manager после входа в Garmin. Попытка сборки без профиля завершилась `Invalid device id: fenix7x`; файл приложения часов **не считается собранным**. Исходники и команды установки включены в комплект. Повторная проверка SDK Manager вне песочницы подтвердила корректную подпись и нотариализацию Apple. Прежнее заключение о повреждении отменено; менеджер успешно открыт на лицензионном соглашении, принятие которого ожидает пользователя.

При первой проверке `adb devices -l` подключённых устройств не было. Позднее по USB обнаружены fēnix 7X Pro Sapphire Solar; модель подтверждена свежими метаданными Garmin Express и сопоставлением с USB-идентификатором. Подробности — `docs/hardware.md`. Установка на Huawei, iPhone и часы, чтение двух реальных завершённых ночей сна и измерение физических сигналов ещё не выполнены.

## Обязательные проверки, которые остаются открытыми

1. Камера на Huawei Pura 70, iPhone 11 и iPhone 17: ориентации, направление pitch, калибровка, лицо/очки/блики/перекрытие и жизненный цикл.
2. Контрольные эпизоды и отрицательный часовой тест: КЧ-01/02/03, внешний звук ≤0,5 с, ≥600 завершённых анализов в каждом 60-секундном интервале, 60 минут устойчивости и расход заряда.
3. Garmin fēnix 7X + Huawei и Apple Watch SE + совместимый iPhone: установка, рабочий обмен, физическая вибрация ≤2 с при включённом и автоматически погасшем экране, отключение/восстановление, отмены и дубли.
4. Доступность Garmin Connect → Health Connect на фактическом Huawei. Отсутствие Health Connect не заменяется ручным вводом или макетом. При невозможности этого пути требуется отдельное согласованное решение; Garmin Health API и сервер не считаются предоставленными.
5. HealthKit/Health Connect: минимум две реальные ночи целевых часов, происхождение и модель, изменения/удаления записей, полнота, часовые пояса и отзыв доступа. Неизвестное/смешанное происхождение не позволяет подтвердить полноту для рекомендации.
6. Полный Xcode, подпись iPhone/Watch, профиль fēnix 7X и постоянный release keystore. Текущая Android-конфигурация использует отладочную подпись для локальной release-сборки.
7. Оформление фактического протокола приёмки и согласование комплекта документации после аппаратных испытаний. Исходные ТЗ/ПЗ не редактировались; новые руководства и технические пояснения находятся в README/docs.

Подробные сценарии и критерии — `docs/acceptance.md`. Программные тесты не доказывают истинную сонливость, медицинскую точность или безопасность вождения. Приложение не предназначено для испытаний в дорожном движении.
