# Подключённое оборудование

## Проверка 15 октября 2026 года

Mac обнаружил Garmin по USB. Garmin Express Service прочитал метаданные устройства в 20:46 по московскому времени. Идентификатор из USB сопоставлен с идентификатором метаданных; персональный идентификатор часов в этот документ не включён.

| Поле | Полученное значение |
|---|---|
| Description | fenix 7X Pro Sapphire Solar |
| PartNumber | 006-B4376-00 |
| SoftwareVersion, исходное значение XML | 2718 |
| Цель Connect IQ | `fenix7xpro` |
| USB | Подключение обнаружено, Garmin Express Service получил доступ |
| Том в `/Volumes` | Отсутствует; обычное копирование через путь диска сейчас недоступно |
| NSControl на часах | Не установлен; сборка ожидает профиль SDK |
| Huawei по ADB | Пока не обнаружен |

Фактически подключена модель Pro. Она добавлена в manifest как дополнительная цель. Базовая цель `fenix7x` из ТЗ остаётся в проекте; проверка Pro сама по себе не считается выполнением приёмки обычной fēnix 7X.

Для сборки на фактические часы требуется профиль `fenix7xpro` из SDK Manager. Подключение физических часов не устанавливает этот профиль автоматически. Повторная проверка SDK Manager вне песочницы подтвердила корректную подпись и нотариализацию Apple (`codesign`: valid on disk; `spctl`: accepted / Notarized Developer ID). Прежнее предупреждение о повреждении было ошибочным результатом ограниченной среды. Менеджер открыт на лицензионном соглашении; принятие ожидает отдельного подтверждения пользователя.

Наличие USB-соединения подтверждает только связь с Mac. Доставка NSControl, физическая вибрация, связь с Huawei и получение записей сна ещё не проверены. Журналы активности и данные здоровья с часов в ходе этой проверки не читались.
