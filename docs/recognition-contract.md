# Контракт распознавания и формат записи (MVP, 25.11.2026)

План и методика: [NSControl — план MVP распознавания](https://claude.ai/artifact/3pSgDXc4yw5zUjhxAcyrtW). Этот файл фиксирует общий контракт для трёх параллельных тредов: «Лаборатория и поток телеметрии», «Движок ARKit», «Методика: зоны взгляда и правила оповещений». Меняется только через PR в `mvp/recognition` с описанием, кто из потребителей затронут.

## Неизменное

- Пороги ТЗ: глаза — обе оценки ниже T не меньше 1,5 с (ФТ-04); голова — наклон относительно калибровки строго больше 20° не меньше 2,0 с при повороте до 30° включительно (ФТ-05). Автоматы `ObservationEngine` получают только `FaceMeasurement`.
- Всё сверх ТЗ (зоны, отвлечение, учёт взгляда вниз) работает под флагом и в режиме приёмки выключается, если оно ослабляет обязательные требования.
- Кадры и видео приложение не сохраняет и не передаёт (ФТ-01), в том числе в Лаборатории и в записи. В запись и поток идут только числа.

## Сигналы лица: `lib/logic/signals.dart`

`FaceSignals` — сигналы одного лица одного кадра в соглашениях водителя. Движок заполняет то, что умеет измерять; `null` значит «не измерено», а не ноль. `DetectedFace.signals` несёт их рядом с прежним `measurement`; `FaceSignals.toMeasurement()` даёт вход автоматов ТЗ.

| Поле | Единицы и знак | ML Kit | ARKit |
|---|---|---|---|
| `headYawLeft` | градусы, > 0 — голова повёрнута влево от водителя | Euler Y после проверки знака | из `ARFaceAnchor.transform` |
| `headPitchDown` | градусы, > 0 — голова вниз | −Euler X (как сейчас) | из `transform` |
| `headRollRight` | градусы, > 0 — к правому плечу | Euler Z после проверки знака | из `transform` |
| `gazeLeft`, `gazeDown` | градусы, взгляд (голова + глаза) относительно камеры | нет | из `lookAtPoint` и `transform` |
| `eyeGazeLeft`, `eyeGazeDown` | градусы, глаз относительно головы | нет | из `leftEyeTransform`/`rightEyeTransform` |
| `eyeOpenLeft`, `eyeOpenRight` | 0..1, 1 — открыт | `leftEyeOpenProbability` | 1 − `eyeBlinkLeft` (или своя проверенная формула) |
| `blendshapes` | 0..1, имена ARKit/MediaPipe, Left/Right — глаз водителя | нет | все 52 или нужные из `Blendshape` |
| `distanceM` | метры до лица | нет | из `transform` |
| `tracked` | лицо надёжно отслеживается | true | `isTracked` |

Знаки каждого движка подтверждаются на iPhone простым тестом в Лаборатории (повернуть голову влево, опустить, наклонить к плечу, посмотреть глазами влево и вниз) до того, как его значения используются в логике. Текущий знак Euler Y и Z у ML Kit в проекте не проверен.

`GazeZone`: `road`, `mirror_left`, `mirror_right`, `mirror_rear`, `instruments`, `console`, `off_camera`, `unknown`. Решает тред методики; Лаборатория только показывает.

## Запись: JSONL, схема 1

Один объект JSON на строку, UTF-8. Время — целые микросекунды монотонной шкалы от начала записи (`atUs`, `capturedUs`, `completedUs`), календарное время только в `meta`. Файл: `nscontrol-<recordingId>.jsonl`.

```
{"type":"meta","schema":1,"recordingId":"…","app":"1.0.0+2","device":"iPhone12,1","os":"iOS 26.2.1","engines":["mlkit_face_detection"],"startedAt":"2026-11-27T10:00:00+03:00","subject":"S1","notes":""}
{"type":"calibration","atUs":…,"profile":{…CalibrationProfile.toJson()…},"zones":{…необязательно…}}
{"type":"frame","engine":"arkit_face_tracking","capturedUs":…,"completedUs":…,"faceCount":1,"signals":{…FaceSignals.toJson()…}}
{"type":"derived","atUs":…,"zone":"mirror_left","eyes":{…ChannelSnapshot.toJson()…},"head":{…},"fatigue":{…}}
{"type":"event","change":"started","event":{…ObservationEvent.toJson()…}}
{"type":"label","atUs":…,"scenario":"bench-v1","step":"mirror_left","edge":"start"}
```

- `frame` пишется на каждый завершённый анализ. В режиме сравнения двух движков на один `capturedUs` приходится две строки с разными `engine`. Если лица нет, `faceCount` 0 и `signals` отсутствует.
- `derived` — то, что приложение решило в этот момент. Программа прогона его не использует: она заново считает решения по `frame`, а `derived` нужен для сверки и для живого экрана.
- `label` — начало и конец шага сценария. Метка — эталон для оценки, детектор эталоном не является (ТЗ, методика ПМИ).
- Неизвестные поля и типы строк читатели пропускают; несовместимое изменение повышает `schema`.

Поток в браузер на Mac передаёт те же объекты (WebSocket, по одному JSON на сообщение).

## Шаги сценария

| `step` | Что делает человек | Ожидаемое событие |
|---|---|---|
| `road` | смотрит на дорогу, моргает как обычно | нет |
| `mirror_left`, `mirror_right`, `mirror_rear` | короткий осмотр зеркала и возврат | нет |
| `blind_spot_left`, `blind_spot_right` | проверка слепой зоны через плечо | нет |
| `intersection_scan` | несколько поворотов влево-вправо, в том числе долгих | нет |
| `instruments` | короткий взгляд на приборы | нет |
| `talk`, `laugh`, `squint`, `yawn` | разговор, смех, прищур, зевок | нет |
| `eyes_closed_1s` | закрыть глаза на 1 с | нет (короче порога) |
| `eyes_closed_2s`, `eyes_closed_3s` | закрыть глаза на 2 и 3 с, голова прямо | `eyes_closed` |
| `head_down_3s` | опустить голову больше чем на 20° на 3 с | `head_pitch_down` |
| `nod` | короткий кивок и возврат | нет |
| `glasses`, `dark` | очки; приглушённый свет | по основному шагу |

Список можно расширять новыми `step`; ожидание для нового шага задаётся в программе прогона.
