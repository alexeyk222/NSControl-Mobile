# NSControl: тон и тексты

Версия 0.2 от 25.11.2026. Все тексты — черновики для дизайна. Ключи (`trip.status.watching`) предлагаются для файла локализации.

## 1. Тон

NSControl говорит как **спокойный штурман**: коротко, по делу, на «вы», без паники в обычной жизни и без вежливых оборотов в тревоге.

| Ситуация | Как звучим | Пример | Как не звучим |
|---|---|---|---|
| Всё хорошо | Одно слово, тихо | «Слежу» | «Наблюдение осуществляется по двум каналам» |
| Проблема техники | Факт + действие | «Не вижу вас. Проверьте телефон на остановке» | «Наблюдение недоступно: лицо не найдено» |
| Совет | Мягко, с причиной | «Вы за рулём 2 часа. Пора сделать перерыв» | «Рекомендуется перерыв 15–20 минут» |
| Тревога | Приказ, 1–3 слова | «Глаза!» | «Длительное закрытие глаз. Остановитесь в безопасном месте для отдыха.» |
| После тревоги | Прямо, без морали | «Вы закрывали глаза. Найдите место для остановки» | «Зарегистрировано событие eyes_closed» |

Правила:
1. **Действие в конце.** Каждое сообщение об ошибке кончается тем, что сделать.
2. **Голосовая фраза не длиннее 8 слов** и понятна без экрана.
3. **Экранный заголовок не длиннее 3 слов** в пути и 6 слов вне поездки.
4. **Числа по-человечески**: «4 ч 50 мин», «2 раза», «12 мин». Никаких «0,3 с», «%», «°» вне режима разработчика и итога.
5. **Не обещаем бодрость.** Не пишем «вы в порядке», «можно ехать безопасно». Пишем, что заметили и что советуем.
6. **Не стыдим.** «Вы закрывали глаза», а не «Вы засыпали за рулём!».
7. **Ё пишем.** Тире длинное с пробелами, неразрывные пробелы перед «ч», «мин», «с».

## 2. Словарь

| Вместо (внутренний термин) | Пишем водителю |
|---|---|
| наблюдение, мониторинг | «слежу», «защита» |
| канал глаз / канал головы | «глаза», «голова» |
| наблюдение ограничено | «Слежу за головой» |
| наблюдение недоступно, лицо не найдено | «Не вижу вас» |
| калибровка | «настройка камеры» (в заголовке), «смотрите на дорогу» (в процессе) |
| сеанс | не показываем |
| событие eyes_closed | «глаза закрывались» |
| событие head_pitch_down | «голова опускалась» |
| отвлечение | «взгляд не на дороге» |
| подтвердить сигнал | «выключить звук», «коснитесь экрана» |
| рекомендация отдыха | «совет» |
| полнота сведений о сне | «все ли ночи записаны» |
| источник сна HealthKit | «Здоровье» (Apple Watch) |
| режим скрытых глаз | «Тёмные очки» |
| держатель перемещён | «Телефон сдвинулся» |
| журнал | «история» (для водителя), «журнал» (в экспорте) |

**Запрещены в основном интерфейсе** (разрешены в режиме разработчика): канал, сеанс, признак, порог, пригодный, автомат, ракурс, Euler, PERCLOS, ML Kit, ARKit, профиль, приёмка, лаборатория, eyes_closed, head_pitch_down, alert_request_latency, Garmin, Body Battery.

## 4. Голосовые фразы: правила

- Синтез речи iOS, русский голос с наилучшим качеством, доступным на устройстве; скорость чуть выше обычной (1,05–1,1).
- Перед фразой уровня «Внимание» — тон-предупреждение 150 мс, чтобы водитель успел переключить внимание.
- Музыка приглушается на время фразы (ducking) и возвращается.
- Одна и та же фраза не чаще раза в 2 минуты.
- Во время тревоги и 5 с после неё звучат только фразы тревоги.
